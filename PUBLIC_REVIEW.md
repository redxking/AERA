# Public review status

**Status: Not open.**

This public repository provides stable access to the AERA 1.2 Working Draft developmental-review candidate. Repository publication does not begin a formal public-review period and is not an invitation to submit comments or implementation evidence.

Before formal review opens, a future dated notice must establish at least:

- exact opening and closing timestamps and time zone;
- an authorized submission channel;
- contribution, attribution, intellectual-property, and derivative-work terms;
- privacy and identity-publication choices;
- moderation, conflict-of-interest, adjudication, and appeal processes;
- comment identifiers, disposition records, and change-control rules; and
- the relationship between the working draft, any later release candidate, and any consensus claim.

No public-review outcome, external validation, multistakeholder consensus, standards-body adoption, or government endorsement should be inferred from this repository.
