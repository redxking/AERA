# Security policy

## Supported material

The current AERA 1.2 Working Draft package is the only material in scope. AERA is technical architecture documentation and supporting data, not production software or a deployed service.

## Reporting

Do not disclose a vulnerability or security-sensitive concern in a public issue, pull request, discussion, or review file.

If GitHub displays **Report a vulnerability** in this repository's Security area, use that private channel. If private vulnerability reporting is unavailable, do not submit sensitive details; a separate private reporting channel has not yet been established.

Reports concerning cited third-party products, standards, publications, or services should be directed to their respective owners unless the issue is specifically an error in AERA's treatment of that source.

Submitting a report does not create a contractual relationship, bounty entitlement, contributor status, confidentiality agreement, or license.
